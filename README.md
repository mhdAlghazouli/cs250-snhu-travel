**How do I interpret user needs and implement them into a program? How do user stories help?**  
I translate user needs into clear user stories (“As a [user], I want [capability] so that [benefit]”). This keeps the “why” visible and helps break work into testable, valuable increments.

**How do I approach developing programs? What Agile processes will I use?**  
Iterative, incremental development with feedback every sprint. I rely on backlog refinement, sprint planning, daily standups, and lightweight demos/tests to stay flexible and deliver value continuously.

**What does it mean to be a good team member in software development?**  
Communicate early, make progress visible, help unblock teammates, write testable code, and respect shared definitions of done. I aim for transparency, accountability, and steady improvement.
